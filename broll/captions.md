# Captions & hashtags

De B-roll Studio zet automatisch een caption klaar per reel. Wil je variatie, gebruik dan
de sjablonen hieronder. De regel: de hook staat al in beeld, dus de caption herhaalt hem
niet letterlijk — die bouwt erop verder.

## Sjablonen

### 1. Uitleg (standaard)
```
{hook}

En dat is precies waar het misloopt: {één zin die de hook uitlegt}.
{één zin met wat je in de plaats moet doen}.

Volg @asklien.ai voor AI die écht voor je werkt.
```

### 2. Lijstje
```
{hook}

3 dingen die ik bij bijna elke KMO zie:
1. {…}
2. {…}
3. {…}

Herkenbaar? Zet een 🔥 in de comments.
```

### 3. Vraag (voor bereik)
```
{hook}

Ik ben benieuwd: {concrete vraag met maar twee mogelijke antwoorden}?

Antwoord hieronder, ik lees alles.
```

### 4. Zachte verkoop (max 1 op 5 posts)
```
{hook}

Dit is exact wat we doen in {Voorsprong / de Challenge}: {één zin resultaat}.

Link in bio.
```

### 5. Persoonlijk
```
{hook}

{twee zinnen eigen ervaring, geen les}

Daarom doe ik het nu zo: {één zin}.
```

## Hashtags

Wissel per post van set. Altijd dezelfde hashtags maakt je bereik smaller, niet breder.

**Set A — breed Vlaams ondernemen**
`#ondernemen #kmo #zelfstandige #ondernemenvlaanderen #ondernemersleven #kmobelgie #vlaanderen`

**Set B — AI en tools**
`#ai #artificialintelligence #claudeai #chatgpt #aitools #automatisatie #prompting`

**Set C — resultaat en tijd**
`#productiviteit #tijdwinst #efficiëntie #workflow #werkslimmer #minderwerkenmeerdoen`

**Set D — merk**
`#asklien #aivoorondernemers #aiinhetnederlands #aiuitleg`

Neem er 8 tot 12 per post: kies één volledige set en vul aan met 3 uit set D.

## Posten

- **Trial reels staan of vallen bij de eerste seconde.** De hook staat vanaf frame 1 in beeld —
  daarom brandt dit systeem hem erin in plaats van hem in de caption te zetten.
- **Voeg muziek toe in Instagram zelf,** niet vooraf. Kies een trending audio met een laag
  aantal gebruiken (onder de 50.000). Zet het volume op ongeveer 40%.
- **Zet de cover op frame 1.** Je hook staat er al op, dus je hoeft geen aparte cover te maken.
- **Post 3 tot 5 reels per week,** verspreid. Alles op één dag lossen werkt tegen je.
- **Laat een reel 48 uur staan** voor je oordeelt. Trial reels lopen trager op gang dan gewone.
- **Wat werkt, film je opnieuw.** Presteert een hook goed, maak er dan drie varianten van
  met andere b-roll. Dat is goedkoper dan een nieuw idee zoeken.

## Bijhouden

Hou het simpel, één regel per reel in een notitie of spreadsheet:

| Datum | Hook | Views | Volgers erbij | Opnieuw doen? |
|-------|------|-------|---------------|---------------|
|       |      |       |               |               |

Na 20 reels weet je welke drie hooks werken. Die drie zijn je formule.
