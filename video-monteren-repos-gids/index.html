4 gratis GitHub-repo's die je video's monteren, terwijl jij toekijkt.

Vier gratis open-sourceprojecten doen de rest op je eigen computer. Per repo zeg ik voor wie het is, wat je installeert en de eerste prompt die je op je eigen beelden loslaat.

Drie dingen voor je begint

01

Je hebt Claude Code of Codex nodig

Claude Code zit bij een betaald Claude-abonnement. Codex zit bij elk ChatGPT-plan, ook het gratis plan, met lagere limieten. Alles in deze gids werkt met allebei. Waar een commando verschilt, zeg ik het.

02

Je computer doet het werk, niet de cloud

Het knippen gebeurt lokaal met FFmpeg, een gratis programma dat al twintig jaar onder zowat elke videotool zit. Je beelden verlaten je computer niet, tenzij je zelf een betaalde dienst koppelt voor ondertitels of stem.

03

Je typt zelf geen commando's

De installatieblokken hieronder plak je in Claude Code met de vraag "installeer dit voor mij". Het legt uit wat het doet en vraagt bevestiging. Een video geef je door het bestand in het venster te slepen.

Eerst de basis installeren, in één prompt

Alle vier draaien op dezelfde gratis onderdelen: Node.js (versie 22 of hoger), FFmpeg, Git en Chrome. OpenMontage wil daarbovenop Python. Je hoeft niet te weten wat dat allemaal is. Open Claude Code of Codex in om het even welke map en plak dit.

PROMPT · DE BASIS
Ik ben contentmaker, geen developer, en ik wil op deze computer video's monteren met AI. Controleer of ik Node.js 22 of nieuwer, FFmpeg met ffprobe, Git, Chrome en Python 3.10 of nieuwer heb. Installeer wat ontbreekt, één stap per keer, en leg me in gewone woorden uit wat elke stap doet voor je ze uitvoert. Toon me op het einde van elk onderdeel het versienummer, zodat ik weet dat het gelukt is.

Over de blokken met commando's hieronder. Die horen in je terminal: Terminal op een Mac, PowerShell op Windows. Eén regel per keer plakken en Enter. Vind je dat eng, plak dan het hele blok in Claude Code en zeg "doe dit voor mij". Dat werkt even goed.

De vier repo's.

Sterrenaantallen zijn van begin november 2026. Bij elke repo: voor wie, wat je nodig hebt, de installatie en de eerste prompt die je op je eigen beelden probeert.

01

Herk Edit Kit: voor wie tegen de camera praat

github.com/nateherkai/herk-edit-kit2.500 sterrenMITMac, Windows, Linux

De eigen montagekit van Nate Herk, gebouwd bovenop HyperFrames (nummer 4). Je geeft het je ruwe opname, het knipt de stiltes en de versprekingen eruit, zet ondertitels erop en bouwt de visuals. Het mooie: het toont je eerst elke knip die het wil maken, en pas na jouw oké gaat het snijden. Dat is precies hoe ik het met een menselijke monteur ook zou willen.

WAT JE NODIG HEBT

Alles uit de basisprompt hierboven, behalve Python. Voor de transcriptie gebruikt het standaard ElevenLabs met je eigen sleutel (betalend per gebruik). Wil je dat niet, vraag dan om gratis Whisper op je eigen computer. Beide staan uitgelegd in de map docs van de repo.

INSTALLATIE
git clone https://github.com/nateherkai/herk-edit-kit.git
cd herk-edit-kit
npm ci
npm run setup
npm test
claude

De laatste regel opent Claude Code in de kit. Gebruik je Codex, typ dan codex in plaats van claude.

EERSTE PROMPT
/edit-video Monteer mijn opname [sleep hier je videobestand in]. Knip de dode momenten en lange pauzes eruit, en toon me elke knip die je wil maken voor je ze maakt. Hou mijn voorbeelden en hoofdpunten, en zet ondertitels erop. Heb ik geen ElevenLabs-sleutel, gebruik dan gratis lokale Whisper voor de transcriptie. Geef me een eerste versie die ik kan nakijken.

In Codex vervang je /edit-video door $edit-video. Voor de rest is de prompt dezelfde.

02

OpenFilm: AI monteert, jij stuurt bij op een echte tijdlijn

github.com/openfilm/openfilm4.200 sterrenMITDesktop-app beschikbaar

Dit is de keuze voor wie het niet helemaal uit handen wil geven. Claude Code of Codex bouwt de montage, en die opent daarna in Studio, een editor in je browser met een echte tijdlijn. Clips inkorten, tekst verschuiven, iets anders stylen: dat doe je gewoon met je muis, zonder een nieuwe prompt te schrijven. Voor de meeste ondernemers die ik begeleid is dit de meest geruststellende instap.

WAT JE NODIG HEBT

Node 22.2 of hoger en FFmpeg, plus Git om versies bij te houden. Geen account. De makkelijkste weg is de desktop-app op openfilm.dev voor Mac of Windows: daar zit alles al in, met een ingebouwde chat voor Claude Code of Codex. Ondertitels en AI-stem of -muziek vragen een dienst als ElevenLabs of OpenAI, met je eigen sleutel, in Studio onder Settings en dan Providers.

INSTALLATIE
mkdir mijn-videos
cd mijn-videos
npx skills add openfilm/openfilm
claude

Als het vraagt, kies je Claude Code of Codex. De eerste keer downloadt het een browserengine van zo'n 100 MB. Geef het een minuut.

EERSTE PROMPT
Maak met OpenFilm een verticale video van 30 seconden uit mijn clip [sleep hier je videobestand in]. Hou mijn sterkste take, knip de pauzes weg en zet een eenvoudige titel vooraan. Open het daarna in Studio zodat ik zelf dingen kan aanpassen op de tijdlijn. Hebben de ondertitels een dienst nodig die ik nog niet gekoppeld heb, zeg me dan welke.
03

OpenMontage: van één lange opname naar een reeks shorts

github.com/calesthio/OpenMontage74.600 sterrenAGPL-3.0Werkt volledig gratis

Je hebt een webinar van een uur opgenomen, een podcastaflevering, een workshop. Daar zitten vijf goeie reels in, maar wie heeft er tijd om ze te zoeken? OpenMontage heeft daar een vaste werkwijze voor, Clip Factory: het zoekt de sterkste momenten, rangschikt ze en knipt ze op formaat. Het is één van een twaalftal ingebouwde pijplijnen voor groter productiewerk, en de enige waar je mee begint.

WAT JE NODIG HEBT

Python 3.10 of hoger, FFmpeg en Node 18 of hoger. Elke API-sleutel is optioneel: zonder sleutels gebruikt het gratis lokale tools voor transcriptie, ondertitels en knippen. Koppel je later een betaalde dienst, dan zegt het je op voorhand wat iets kost voor het geld uitgeeft. Dat vind ik een goed teken.

INSTALLATIE
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup
claude

Op Windows is make meestal niet geïnstalleerd. Plak dan de link van de repo in Claude Code en vraag om de Windows-installatie uit de README te volgen. Dat lost het zelf op.

EERSTE PROMPT
Gebruik de Clip Factory-pijplijn op mijn opname [sleep hier je videobestand in]. Zoek de 3 sterkste momenten die werken als verticale clips van 30 tot 60 seconden en rangschik ze. Zet op elke clip ondertitels per woord. Gebruik alleen gratis lokale tools, en toon me het plan voor je iets rendert.
04

HyperFrames: titels, animaties en motion graphics

github.com/heygen-com/hyperframes77.300 sterrenApache-2.0Van HeyGen

Het open-sourceproject van HeyGen dat webpagina's omzet in video. Klinkt technisch, komt hierop neer: alles wat je in een browser kan tonen, kan HyperFrames animeren en renderen als MP4. Titelkaarten, een naambalk onderaan die inschuift, cijfers die oplopen, een logo-animatie. Het is ook de motor onder Herk Edit Kit. Bekijk de showcase op hyperframes.heygen.com/showcase voor ideeën, en reken erop dat je er een uur kwijt bent.

WAT JE NODIG HEBT

Node 22 of hoger en FFmpeg. Gratis, en het rendert op je eigen computer.

INSTALLATIE
cd mijn-videos
npx skills add heygen-com/hyperframes
claude

Heb je OpenFilm overgeslagen, typ dan eerst mkdir mijn-videos. Als het keuzemenu opent staat er niets aangevinkt: kies de groep Core Skills, en dan Claude Code of Codex. In Claude Code kan je het ook als plugin installeren met de twee commando's uit de README.

EERSTE PROMPT
Maak met /hyperframes een geanimeerde titelkaart van 5 seconden met de tekst [de titel van je video] in [je huisstijlkleuren]. Maak daarna een naambalk onderaan met mijn naam en @[je handle] die over mijn clip [sleep hier je videobestand in] inschuift. Toon me eerst een preview, en render het dan als MP4.
ÉÉN REGEL OVER VEILIGHEID

Een repo installeren is code van een ander op je computer draaien

Dat is geen reden om het niet te doen, wel om te kijken naar wie je binnenlaat. Deze vier hebben elk duizenden sterren en zijn de voorbije weken nog bijgewerkt. Dat zijn de twee dingen waar ik altijd naar kijk, en ik leg ze uit in mijn gids over GitHub-repo's zonder code. En nog dit: je API-sleutels horen in het .env-bestand dat de installatie aanmaakt. Nooit in een chatvenster.

Twijfel je bij een repo die hier niet in staat? Plak de link in Claude met webzoeken aan en vraag: hoeveel sterren, wanneer laatst gewijzigd, is het gearchiveerd, en wat installeert het precies op mijn computer. Pas dan beslis je.

Vragen die ik hierover krijg

Moet ik kunnen programmeren om dit te gebruiken?

Nee. Je typt in gewone taal wat je wil, en Claude Code of Codex voert de commando's uit. De installatiestappen plak je als één blok in Claude Code met de vraag om het voor jou te doen. Het legt uit wat het doet en vraagt bevestiging voor elke stap.

Werkt dit met een gratis account?

Claude Code vraagt een betaald Claude-abonnement. Codex zit bij elk ChatGPT-plan, ook het gratis plan, met lagere limieten. De vier repo's zelf zijn gratis en open source. Alleen als je een dienst als ElevenLabs koppelt, betaal je per gebruik.

Zijn mijn beelden veilig?

Het knippen en renderen gebeurt op je eigen computer. Alleen als je een betaalde dienst koppelt voor transcriptie of stem, gaat er audio naar die dienst. Elke repo heeft een gratis lokale optie, en ik zeg er in elke prompt bij dat het die moet gebruiken als je geen sleutel hebt.

Vervangt dit CapCut of Premiere?

Voor talking-head video's, shorts uit lange opnames en animaties vervangt het al een groot deel van het handwerk. Voor fijne kleurcorrectie of complexe montages blijft een klassiek programma handiger. OpenFilm zit daar mooi tussenin: AI bouwt, jij stuurt bij op de tijdlijn.

Welke zou jij kiezen als je er maar één mag?

Film je vooral jezelf, dan Herk Edit Kit. Heb je lange opnames liggen, dan OpenMontage. Twijfel je, begin dan met OpenFilm: de desktop-app installeert alles voor je en je ziet meteen wat er gebeurt.
